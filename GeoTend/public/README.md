PWA Assets - GeoTend
====================

This folder contains Progressive Web App assets for GeoTend.

## Main Logo
**logo.svg** - SVG-based logo used for:
- Splash screen on app launch
- Home screen icon
- Browser icon
- PWA manifest

The logo automatically scales to any size thanks to SVG format.

## Installation

### On Android
1. Open the app in Chrome
2. Tap the menu (⋯) button
3. Select "Install app" or "Add to Home screen"

### On iOS (Safari)
1. Open the app in Safari
2. Tap the Share button
3. Select "Add to Home Screen"
4. Tap "Add"

### On Windows/Desktop
1. Open the app in Chrome/Edge
2. Click the install icon in the address bar
3. Click "Install"
